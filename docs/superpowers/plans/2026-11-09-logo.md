# Logo (J2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder lamp logo with the J2 mark ("light rising from a line of text"): source files in `assets/brand/`, and the site's favicon, nav logo and share image.

**Architecture:** Hand-written SVG files on a 64-unit grid, pinned by a stdlib-only `unittest` file (`scripts/test_brand.py`) that the Pages workflow runs. The lockups' "Lucerna" text is converted to paths once by a dev-only script, and the resulting SVGs are committed. The site keeps its no-build setup.

**Tech Stack:** SVG, HTML/CSS, Python 3 stdlib (`xml.etree`, `unittest`). Only for the lockup script: `fonttools`, `brotli`, `uharfbuzz`, installed in a throwaway venv outside the repo.

**Spec:** [`docs/superpowers/specs/2026-11-09-logo-design.md`](../specs/2026-11-09-logo-design.md)

## Global Constraints

- Grid `viewBox="0 0 64 64"`, halo centre (32, 42).
- Colours: accent `#4f8cff`, ink `#e6eaf2`, ground `#080b12`, app-icon tile `#0f1420`, tile border `#1b2232`.
- Full mark, at 24 px and above: halos r = 22/14/7 at opacity .18/.45/1; line `M4 44H60`, width 5, round caps.
- Small mark, below 24 px: halos r = 22 at opacity .3 and r = 10 at opacity 1; line width 6.
- Tight crop for lockups and the nav: `viewBox="1 18 62 29"`.
- Wordmark: Bricolage Grotesque wght 650, letter-spacing −0.02em, converted to paths. The bottom of the line sits on the text baseline. Mark height = 1.25 × cap height. Gap = 0.3 × mark height.
- Minimum clear space: 7 grid units (the core radius).
- No `.icns`, no palette or font changes, and no new runtime dependency for the site or for CI.

## Review Focus

1. **Favicon on a light browser tab:** an ink-coloured line vanishes on a light tab. The favicon must default to a `#080b12` line and switch to `#e6eaf2` under `prefers-color-scheme: dark`. Pinned by `test_favicon_adapts_to_scheme` (Task 3).
2. **Clipped line caps:** a crop narrower than x 1.5–62.5 cuts the round caps. Pinned by `test_lockup_viewbox_contains_mark` (Task 2) and `test_nav_logo` (Task 3).
3. **Lockup depends on an installed font:** a `<text>` element would render in a fallback font on any machine without Bricolage. Pinned by `test_lockups_have_no_text` (Task 2).
4. **Leftover lamp:** any file under `site/` that still contains the old flame path. Pinned by `test_no_old_lamp_in_site` (Task 3).
5. **Mono mark drawing in a fixed colour or translucency:** pinned by `test_mark_mono_is_single_colour` (Task 1).

### Task 2: Wordmark lockups

**Files:**
- Create: `scripts/gen-lockup.py` (dev-only, not run in CI)
- Create: `assets/brand/lockup-dark.svg`, `assets/brand/lockup-light.svg`, `assets/brand/README.md`

**Interfaces:**
- Consumes: `MARK_D`, `paths()`, `ROOT` (Task 1).
- Produces: `python3 scripts/gen-lockup.py --ink <hex> --out <file>` writes one lockup SVG.

- [ ] **Step 1: Write the failing tests**
  - `test_lockups_have_no_text`: for both lockups, no `<text>` or `<tspan>` element anywhere.
  - `test_lockup_contains_mark`: the first 3 path d values equal `MARK_D[:3]` (inside a `<g transform>` placing the tight-cropped mark); the line path d is `MARK_D[3]`.
  - `test_lockup_colours`: in `lockup-dark.svg` the line stroke and every wordmark glyph fill are `#e6eaf2`; in `lockup-light.svg` both are `#080b12`; halos stay `#4f8cff` in both.
  - `test_lockup_viewbox_contains_mark`: the root viewBox has 4 numbers, with width and height > 0. Under the mark group's transform, mark x 1.5 and 62.5 (y 18 and 47) map inside the viewBox with at least 7 grid units × scale of margin on every side.

- [ ] **Step 2: Run them and confirm they fail**

Run: `python3 -m unittest scripts/test_brand.py -v`
Expected: the 4 new tests error with `FileNotFoundError`; the Task 1 tests still pass.

- [ ] **Step 3: Write `scripts/gen-lockup.py`**

- Docstring: setup is `python3 -m venv /tmp/lucerna-brand && /tmp/lucerna-brand/bin/pip install fonttools brotli uharfbuzz`; run it with `/tmp/lucerna-brand/bin/python scripts/gen-lockup.py`.
- Load `site/fonts/BricolageGrotesque-latin-wght.woff2`.
  - Shape "Lucerna" with `uharfbuzz`, variations `{"wght": 650}` and features defaults, so kerning applies.
  - Get the outlines from `fontTools.varLib.instancer.instantiateVariableFont(font, {"wght": 650})` (or keep `opsz` at its default if the font has that axis), drawn with `SVGPathPen`.
  - Flip y so the baseline is y = 0 and ascenders are negative.
- Letter-spacing: add −0.02 × UPM after every glyph except the last.
- Units: font size 100 (1 em = 100 output units), cap height H = `OS/2.sCapHeight` scaled.
- Mark: tight crop (x 1.5–62.5, y 18–47) scaled by `s = 1.25 × H / 29`.
  - Place it so its y = 46.5 (the bottom of the line) is at baseline y = 0.
  - Place the text at x = mark right edge + `0.3 × 29 × s`.
- ViewBox: the union of mark and text bounds, padded by `7 × s` on every side.
- Output: the mark in a `<g transform="translate(..) scale(s)">` holding the 4 `MARK_D` paths, with the line stroke set to `--ink`. Then one `<path>` per glyph with `fill=--ink`. Round numbers to 2 decimals.

- [ ] **Step 4: Generate both files**

```bash

/tmp/lucerna-brand/bin/python scripts/gen-lockup.py --ink '#080b12' --out assets/brand/lockup-light.svg
```
