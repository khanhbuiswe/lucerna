# Integrated Terminal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A terminal panel in Lucerna that runs agent CLIs (Claude Code, Codex) and TUIs (vim, htop) smoothly next to the code. The panel sits at the bottom by default and can move to the right. It has tabs, theme colours, selection, copy and paste, scrollback, resizing, and ⌘+click links that open files in the editor.

**Architecture:**
- A new gpui-free crate `lucerna-terminal` wraps `alacritty_terminal` 0.26 behind Lucerna's own types. It covers the PTY, the I/O thread, event batching, per-frame snapshots, key and mouse encoding, run batching, colours, link detection and the foreground process.
- `lucerna-workbench` adds:
  - a generic panel frame (`layout/panel.rs`);
  - a `terminal/` module with `TerminalPanel`, `TerminalView` and `TerminalElement`;
  - key routing in `dispatch_key`;
  - terminal colours in `lucerna-theme`.

**Tech Stack:** Rust 2024, `alacritty_terminal = "0.26"` (new), `futures`, `regex`, `libc` (unix), gpui (workbench only).

**Spec:** `docs/superpowers/specs/2026-11-13-terminal-design.md`. Research: `docs/research/2026-11-13-terminal.md`. Each task cites spec sections; read them.

## Review Focus

1. **Zero-size or tiny panel.** A collapsed or freshly created panel, or a resize to a few pixels, must never resize the PTY to 0 rows or 0 columns, because alacritty panics. Clamp to ≥ 1×1 and keep the spec minimum for the sash. The test goes in Task 1 (`resize_clamps_to_one_cell`) and Task 8 (`zero_bounds_do_not_resize_to_zero`).
2. **A broken shell.** If `$SHELL` or the profile path does not exist, or the shell exits at once with a non-zero code, the tab stays open and shows the exit line instead of vanishing or panicking. The test goes in Task 1 (`spawn_missing_shell_errors`) and Task 12 (`nonzero_exit_keeps_tab`).
3. **Wide and combining characters at a line edge.** Vietnamese with combining marks, CJK and emoji in the last column must not shift later cells or panic run batching. The test goes in Task 3 (`wide_char_in_last_column`, `combining_marks_join_previous_cell`).
4. **Child processes outliving the tab or window.** Closing a tab or window must hang up the PTY so the shell and the agent get SIGHUP. Zombie `claude` processes are not allowed. The test goes in Task 1 (`drop_hangs_up_child`).
5. **A flood of output.** `yes`, `cat` of a huge file, or a hidden panel with a busy agent must not grow memory beyond the scrollback cap or stall the UI thread. Batching must coalesce wakeups. The test goes in Task 1 (`batch_coalesces_wakeups`, `scrollback_is_capped`) and is measured in Task 13.

  - `Terminal::spawn` builds `alacritty_terminal::tty::Options` (shell, cwd, env, `drain_on_exit: true`), calls `tty::new`, creates `Term` with `Config { scrolling_history: opts.scrollback.min(100_000), .. }` inside `Arc<FairMutex<_>>`, and starts `EventLoop::new(…).spawn()`.
  - A listener maps alacritty events onto the unbounded channel:
    - `Wakeup`, `Title`, `ResetTitle`, `Bell`, `ChildExit` (to an exit code, or `None` when killed by a signal), and `Exit` (to `Exited(None)` if no `ChildExit` came first).

  - `Drop` sends `Msg::Shutdown` and drops the PTY, which hangs up the child.
