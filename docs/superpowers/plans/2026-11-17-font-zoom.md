# Font zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ⌘= / ⌘+ / ⌘− / ⌘0 change the code font size in every view and every window, for one running session, without writing settings.

**Architecture:** A GPUI global `FontZoom` (new module `font_zoom.rs`) holds the px offset relative to `editor.fontSize`. `WindowSettings` observes this global and calls `notify`, so every view that observes settings (`CodeView`, excerpt list, terminal) re-reads the font size through `font_zoom::zoomed`. The existing per-view zoom (`CodeView::zoom`) is removed.

**Tech Stack:** Rust, GPUI, crate `lucerna-workbench`.

**Spec:** `docs/superpowers/specs/2026-11-17-font-zoom-design.md`

## Global Constraints

- Cargo: `export PATH="/opt/homebrew/opt/rustup/bin:$PATH"`. Run `scripts/prune-target.sh` before every `cargo test`; if `target/release` exists, delete it first (unless `pgrep -x cargo` shows another session building). Do not set `CARGO_TARGET_DIR`.
- Font size limits: 6–100 px everywhere (replacing the old 6–40).
- Step: ±1 px per press. At a limit, do nothing (no change, no message).
- Do not write `settings.json`, do not save to app state; it is lost when the app quits.
- Every string shown is English. The message has exactly the form `Font Size: 16`.
- VS Code command IDs: `editor.action.fontZoomIn`, `editor.action.fontZoomOut`, `editor.action.fontZoomReset`; titles "Editor Font Zoom In" / "Editor Font Zoom Out" / "Editor Font Zoom Reset".
- Commit: stage each file by path; trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Zoom, then open a new tab: the new tab must be at the zoomed size (the main bug of the old version) — test `zoom_applies_to_every_view` in Task 2.
2. Zoom, then edit `editor.fontSize` in `settings.json`: the size goes to exactly the new value, without adding the old offset — test `user_font_size_change_resets_zoom` in Task 2.
3. Press ⌘= repeatedly at 100, then ⌘− once: it must drop to 99 right away, with no "debt" from the extra presses — test `next_delta_clamps` in Task 1.
4. Zoom while scrolled to the middle of a file: the top row stays the same — test `zoom_keeps_top_row` in Task 2.
5. A terminal with its own `terminal.integrated.fontSize`: no zoom — test `terminal_with_own_size_ignores_zoom` in Task 3.

### Task 1: Global `FontZoom`

**Files:**
- Create: `crates/lucerna-workbench/src/font_zoom.rs`
- Modify: `crates/lucerna-workbench/src/lib.rs` (add `pub mod font_zoom;` in alphabetical order)
- Modify: `crates/lucerna-workbench/src/window_settings.rs` (add a field `_zoom: Subscription`)

**Interfaces:**
- Produces:
  - `pub const MIN_FONT_SIZE: f32 = 6.;` `pub const MAX_FONT_SIZE: f32 = 100.;`
  - `pub struct FontZoom { delta: f32, user_size: Option<f32> }` + `impl Global`. `user_size` is the User-layer `editor.fontSize` (from `AppState::settings.get::<f32>("editor.fontSize", None)`) at the time of the last zoom.
  - `pub fn base_size(settings: SettingsView<'_>, language: Option<&str>) -> f32` — `editor.fontSize`, default 14, clamped to 6–100.
  - `pub fn zoomed(base: f32, cx: &App) -> f32` — `(base + effective delta).clamp(6, 100)`. The effective delta is `delta` if `user_size` equals the current User-layer value, otherwise 0 (lazy reset: once the settings change the zoom is gone, no observer needed).
  - `pub fn step(base: f32, by: f32, cx: &mut App) -> Option<f32>` — the new size, or `None` when already at the limit (in which case no `set_global`).
  - `pub fn reset(base: f32, cx: &mut App) -> Option<f32>` — `Some(base)` if the effective delta is non-zero, otherwise `None`.
  - `fn next_delta(base: f32, delta: f32, by: f32) -> f32` (private) — `(base + delta + by).clamp(MIN, MAX) - base`.

#[gpui::test]
fn zoom_applies_to_every_view(cx: &mut TestAppContext) {
    init(cx, None);
    let (wb, cx) = workbench(cx);
    let a = open(&wb, "a.txt", "text\n", cx);
    run(&wb, "editor.action.fontZoomIn", cx);
    run(&wb, "editor.action.fontZoomIn", cx);
    assert_eq!(a.read_with(cx, |v, _| v.font_size()), 16.);
    let b = open(&wb, "b.txt", "text\n", cx);
    assert_eq!(b.read_with(cx, |v, _| v.font_size()), 16.);
    run(&wb, "editor.action.fontZoomReset", cx);
    draw(cx);
    assert_eq!(a.read_with(cx, |v, _| v.font_size()), 14.);
    assert_eq!(b.read_with(cx, |v, _| v.font_size()), 14.);
