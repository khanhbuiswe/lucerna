# Font zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ⌘= / ⌘+ / ⌘− / ⌘0 đổi cỡ chữ code ở mọi view, mọi cửa sổ, trong một phiên chạy, không ghi settings.

**Architecture:** Một global GPUI `FontZoom` (module mới `font_zoom.rs`) giữ độ lệch px so với `editor.fontSize`. `WindowSettings` observe global này và `notify`, nên mọi view đang observe settings (`CodeView`, excerpt list, terminal) tự đọc lại cỡ chữ qua `font_zoom::zoomed`. Zoom theo từng view hiện có (`CodeView::zoom`) bị bỏ.

**Tech Stack:** Rust, GPUI, crate `lucerna-workbench`.

**Spec:** `docs/superpowers/specs/2026-11-17-font-zoom-design.md`

## Global Constraints

- Cargo: `export PATH="/opt/homebrew/opt/rustup/bin:$PATH"`. Chạy `scripts/prune-target.sh` trước mỗi lần `cargo test`; nếu có `target/release` thì xóa trước (trừ khi `pgrep -x cargo` thấy session khác đang build). Không đặt `CARGO_TARGET_DIR`.
- Giới hạn cỡ chữ: 6–100 px ở mọi chỗ (thay 6–40 cũ).
- Bước: ±1 px mỗi lần bấm. Chạm giới hạn thì không làm gì (không đổi, không báo).
- Không ghi `settings.json`, không lưu vào app state; mất khi thoát app.
- Mọi chuỗi hiện ra là tiếng Anh. Thông báo đúng dạng `Font Size: 16`.
- ID lệnh của VS Code: `editor.action.fontZoomIn`, `editor.action.fontZoomOut`, `editor.action.fontZoomReset`; tiêu đề "Editor Font Zoom In" / "Editor Font Zoom Out" / "Editor Font Zoom Reset".
- Commit: stage từng file theo đường dẫn; trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Task 1: Global `FontZoom`

**Files:**
- Create: `crates/lucerna-workbench/src/font_zoom.rs`
- Modify: `crates/lucerna-workbench/src/lib.rs` (thêm `pub mod font_zoom;` theo thứ tự abc)
- Modify: `crates/lucerna-workbench/src/window_settings.rs` (thêm field `_zoom: Subscription`)

**Interfaces:**
- Produces:
  - `pub const MIN_FONT_SIZE: f32 = 6.;` `pub const MAX_FONT_SIZE: f32 = 100.;`
  - `pub struct FontZoom { delta: f32, user_size: Option<f32> }` + `impl Global`. `user_size` là `editor.fontSize` lớp User (từ `AppState::settings.get::<f32>("editor.fontSize", None)`) lúc zoom lần cuối.
  - `pub fn base_size(settings: SettingsView<'_>, language: Option<&str>) -> f32` — `editor.fontSize`, mặc định 14, kẹp 6–100.
  - `pub fn zoomed(base: f32, cx: &App) -> f32` — `(base + delta hiệu lực).clamp(6, 100)`. Độ lệch hiệu lực = `delta` nếu `user_size` bằng giá trị lớp User hiện tại, ngược lại 0 (reset lười: settings đổi là zoom mất, không cần observer).
  - `pub fn step(base: f32, by: f32, cx: &mut App) -> Option<f32>` — cỡ mới, hoặc `None` khi đã ở giới hạn (khi đó không `set_global`).
  - `pub fn reset(base: f32, cx: &mut App) -> Option<f32>` — `Some(base)` nếu độ lệch hiệu lực khác 0, ngược lại `None`.
  - `fn next_delta(base: f32, delta: f32, by: f32) -> f32` (riêng tư) — `(base + delta + by).clamp(MIN, MAX) - base`.

#[gpui::test]
fn zoom_applies_to_every_view(cx: &mut TestAppContext) {
    init(cx, None);
    let (wb, cx) = workbench(cx);
    let a = open(&wb, "a.txt", "text\n", cx);
    run(&wb, "editor.action.fontZoomIn", cx);
    run(&wb, "editor.action.fontZoomIn", cx);
    assert_eq!(a.read_with(cx, |v, _| v.font_size()), 16.);
    let b = open(&wb, "b.txt", "text\n", cx);
    assert_eq!(b.read_with(cx, |v, _| v.font_size()), 16.);
    run(&wb, "editor.action.fontZoomReset", cx);
    draw(cx);
    assert_eq!(a.read_with(cx, |v, _| v.font_size()), 14.);
    assert_eq!(b.read_with(cx, |v, _| v.font_size()), 14.);
}

#[gpui::test]
fn zoom_keys_and_limits(cx: &mut TestAppContext) {
    init(cx, Some(r#"{ "editor.fontSize": 99 }"#));
    let (wb, cx) = workbench(cx);
    let view = open(&wb, "a.txt", "text\n", cx);
    cx.simulate_keystrokes("cmd-= cmd-shift-=");
    draw(cx);
    assert_eq!(view.read_with(cx, |v, _| v.font_size()), 100.);
    cx.simulate_keystrokes("cmd--");
    draw(cx);
    assert_eq!(view.read_with(cx, |v, _| v.font_size()), 99.);
    cx.simulate_keystrokes("cmd-0");
    draw(cx);
    assert_eq!(view.read_with(cx, |v, _| v.font_size()), 99.);
}

#[gpui::test]
fn zoom_shows_font_size(cx: &mut TestAppContext) {
    init(cx, None);
    let (wb, cx) = workbench(cx);
    open(&wb, "a.txt", "text\n", cx);
    run(&wb, "editor.action.fontZoomIn", cx);
    let shown = cx.update(|window, cx| {
        lucerna_workbench::status_message::current(window.window_handle().window_id(), cx)
            .map(|m| m.to_string())
    });
    assert_eq!(shown.as_deref(), Some("Font Size: 15"));
}

#[gpui::test]
fn zoom_keeps_top_row(cx: &mut TestAppContext) {
    init(cx, None);
    let (wb, cx) = workbench(cx);
    let text = "line\n".repeat(500);
    let view = open(&wb, "a.txt", &text, cx);
    view.update(cx, |v, cx| v.set_scroll_top_row(200, cx));
    draw(cx);
    run(&wb, "editor.action.fontZoomIn", cx);
    draw(cx);
    assert_eq!(view.read_with(cx, |v, _| v.scroll_top_row()), 200);
}

#[gpui::test]
fn user_font_size_change_resets_zoom(cx: &mut TestAppContext) {
    init(cx, None);
    let (wb, cx) = workbench(cx);
    let view = open(&wb, "a.txt", "text\n", cx);
    run(&wb, "editor.action.fontZoomIn", cx);
    cx.update(|_, cx| {
        cx.update_global::<AppState, _>(|s, _| {
            s.settings.set_layer(Layer::User, r#"{ "editor.fontSize": 20 }"#).unwrap()
        })
    });
    draw(cx);
    assert_eq!(view.read_with(cx, |v, _| v.font_size()), 20.);
}
