# Nhóm 1 sửa lỗi P3: lưu file — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sửa mọi lỗi của "Nhóm 1: Lưu file" (T1-1, T1-2, T1-3, T1-5, T1-6, T1-7, T2-4, hai giới hạn hot exit) trên nhánh `claude/p3-save`, mỗi lỗi có test.

**Architecture:**
- `lucerna-text` (không gpui) nhận các thay đổi ở tầng byte: cờ `lossy` khi decode, stamp lấy từ handle của file vừa ghi, tên file tạm ≤ 255 byte, và một sổ `TempFiles` ghi các file tạm đang dùng.
- `lucerna-workbench` nối chúng vào luồng lưu có sẵn (`Documents::save`, `WriteJob`, `AutoSave`), thêm thanh báo lossy dùng chung component với thanh conflict, hộp thoại trước lần lưu đầu, và chờ lưu xong trong `quit()`.
- Hot exit: `BackupHeader.lossy`, và hai sửa ở đường khởi động (`app.rs`, `router.rs`) để cửa sổ một file có bản sao lưu luôn được mở lại.

**Tech Stack:** Rust 1.99, GPUI (`b5cd310`), `encoding_rs`, `chardetng`, `tempfile`, `serde`.

**Spec:** `docs/superpowers/specs/2026-11-17-p3-fixes-design.md` (§5 "Nhóm 1", §6). Đọc kèm mục lỗi trong `docs/superpowers/reviews/2026-11-15-release-flow-review.md` và §5.4 của `docs/superpowers/specs/2026-11-16-hot-exit-design.md`.

## Quyết định của plan (spec để ngỏ)

- **Cờ `lossy` sống trong `Buffer`**, cạnh `has_bom`: `from_decoded` và `set_disk_state` lấy từ `Decoded`, nên mọi lần load, reload, merge đều tính lại. Lưu thành công thì `clear_lossy()`.
- **Đồng ý (§6.4) và Dismiss (§6.3)** là hai cờ của `Document` (`lossy_consent`, `lossy_dismissed`), đặt lại về `false` mỗi khi document nhận một bản decode mới từ đĩa (`take_buffer`, `apply_merge`, `apply_disk`). Không lưu qua hot exit.
- **Nút của hộp thoại lossy:** `[PromptButton::new("Cancel"), PromptButton::new("Save")]`. Trên macOS, NSAlert gán Return cho nút đầu, nên Return là Cancel đúng như spec. Xem "Lưu ý cho người duyệt" ở cuối.
- **T2-4:** sổ file tạm là `lucerna_text::TempFiles`, một bản dùng chung cho app (gpui `Global` trong `save.rs`); hook `on_app_quit` được đăng ký ở lần dùng đầu. Thời hạn chờ là `QUIT_SAVE_TIMEOUT = 5 s`.
- **Hot exit (b), đường Finder:** khi app khởi động vì Finder mở một file, chỉ mở lại cửa sổ một file có bản sao lưu (không mở lại session folder, giữ như hiện nay).

## Lưu ý cho người duyệt

- **Nút mặc định của hộp thoại lossy (§6.4 "Cancel là mặc định"):** GPUI `b5cd310` trên macOS để NSAlert gán Return cho nút đầu, gán Escape cho nút `PromptButton::Cancel` (thay mất Return nếu nó đứng đầu), và đặt focus (phím Space) vào nút không-cancel cuối cùng. Với `[Other("Cancel"), Other("Save")]` thì Return = Cancel nhưng Space = Save, và Escape tuỳ NSAlert. Cần thử tay; nếu không chấp nhận được thì phải chọn: đổi spec (Save mặc định như các hộp thoại khác) hoặc patch GPUI.
- **T2-4, ngoại lệ hardlink:** `write_in_place` không có file tạm, nên khi bị cắt giữa chừng (quá 5 s, hoặc Dock Quit) file có hardlink có thể bị cụt. Plan không xử lý; spec ghi "File gốc vẫn nguyên trong mọi trường hợp".
