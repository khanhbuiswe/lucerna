Live from disk

Files reload the moment an agent saves them. The explorer marks what changed outside Lucerna, and open tabs keep your scroll position and folds.

Quick Open

One box for files, commands with > and line numbers with :. Results show up within a frame, even on very large repos.

Project search

Ripgrep's engine with case, whole word, regex and include or exclude globs. Results stream into the sidebar, grouped by file.

Tabs and splits

Preview tabs in italics that you pin with a double-click, editor groups that remember their widths, and Ctrl+Tab through recent files.

A real code view

Tree-sitter highlighting, minimap, indent folding, bracket matching, word wrap and find in file. Read-only for now, so nothing changes by accident.

Your settings

settings.json and keybindings.json with VS Code semantics, hot reloaded. Themes use Zed's JSON format; One Dark and One Light are built in.

No AI inside

Your agent already lives in the terminal.

Lucerna has no chat panel, no ghost text and no MCP server. It shows you what changed and gets out of the way.

Native

Rust and GPUI, drawn on the GPU.

No Electron, no web view. One window per luc call, a few crates you can read in an afternoon.

Open source

MIT or Apache 2.0, your choice.

No GPL dependencies, checked by cargo deny in CI. Fork it, ship it, embed it.

FAQ

Questions people ask

Can I edit code in Lucerna?

Not yet. Phase 1 is a read-only viewer so nothing changes behind your agent's back. You can select and copy text. Full editing arrives in Phase 4.

Why no AI features?

The people Lucerna is for already run Claude Code, Codex or another agent in a terminal. A second assistant inside the editor would only compete for attention.

Will my VS Code settings work?

Lucerna reads settings.json and keybindings.json with the same layering and semantics as VS Code, and ships VS Code's default macOS shortcuts.

Is it related to Zed?

Lucerna uses GPUI, Zed's Apache-licensed UI framework, and reads Zed's theme format. Everything else is written from scratch, with no GPL code from Zed.

Does Lucerna collect any data?

No. There is no telemetry and no account. Logs stay on your machine in ~/Library/Logs/Lucerna.
