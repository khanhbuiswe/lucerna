Rust, drawn on the GPU.

Lucerna is native code from end to end. Its window is drawn by GPUI, the GPU-accelerated UI framework from the Zed project, so opening a repo or reloading a file never waits on a browser engine.

The app
One native app of 50 MB, with the luc command beside it.
Rendering
GPUI on Metal. Linux and Windows are planned, and GPUI already supports both.
License
MIT or Apache-2.0. No GPL dependencies, checked by cargo deny on every change.

Minimal, and it already knows your keys.

A file tree, tabs, a terminal and your git changes, and little else on screen. Shortcuts, settings.json and keybindings.json work the way they do in VS Code, so there is nothing new to learn.

No AI inside. Bring your own agent.

You already have an agent that writes code. Lucerna doesn't add a second one. It gives you a quiet place to check the work.

  1. Your agent writes

    Claude Code, Codex or a desktop app edits files in your repo.

  2. Lucerna shows

    Open files reload in place. Changed files light up in the tree and the gutter marks every changed line.

  3. You review

    Read the diff, fix a line by hand, run the tests in the built-in terminal.

Why not VS Code?

VS Code runs on Electron. Lucerna keeps its shortcuts and setting names, without a browser engine underneath.

Why not Zed?

Zed is fast too, and it is AI-first, with its own agent panel, edit predictions and sign-in. Lucerna has no AI features and needs no account, so the agent stays the tool you already use.

Free, open source, and almost ready.

The first release for macOS on Apple silicon is coming to GitHub Releases. Until then, you can build it yourself with Rust and the Xcode Command Line Tools.

Questions

Can I edit code in Lucerna?

Yes. Typing, undo, save, auto-closing brackets and Vim keys if you want them. When your agent writes to a file you have unsaved changes in, Lucerna merges the two and asks only when they overlap. Multi-cursor and completion come later.

Is it related to Zed?

Lucerna uses GPUI, Zed's Apache-licensed UI framework, and can install themes, icon themes and languages from Zed's extension registry. Everything else is written from scratch, with no GPL code.

Does Lucerna collect any data?

No. There is no telemetry and no account. Logs stay on your machine in ~/Library/Logs/Lucerna.
